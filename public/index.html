Hotpath

A cache for a slow query, built to stay correct while data changes, servers multiply and Redis fails. Every button runs the real code against real Postgres and Redis.

"Servers" here are separate cache instances in one process, each with its own memory and Redis connections. This is a small free host, so compare the numbers with each other. The measured benchmarks are in the repository.
